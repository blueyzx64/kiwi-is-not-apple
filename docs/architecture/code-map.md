# Kiwi (is not Apple): code map (v3 layout)

> **Summary (read this and you can stop):**
> 1. `extension.js` is the composition root: it runs the settings migrations, puts back any GNOME
>    setting a crashed session still held (`core/originals.js`), builds the core services and
>    starts the feature registry with one `ctx`. A one-shot cleanup of what Kiwi 2.x wrote into
>    the user's files runs in the background (`lib/cleanup/`).
> 2. `features.js` lists every feature: an id, its on/off key (or `when`), a lazy `load()`, and
>    `conflictsWith` / `needs` for shared resources. `lib/featureRegistry.js` starts and stops
>    them edge-triggered, in list order, and only loads the modules of features that are on.
> 3. `core/` holds the shared desktop picture every feature reads (windows, apps, focus,
>    workspaces, monitors), edge ownership and the work area, motion rules, a typed event hub,
>    the saved originals of GNOME keys, and the 2.x coordinators (panel slots, window flags,
>    notification routing, MPRIS). Pure `*Model.js` files, thin Shell adapters.
> 4. `features/<name>/` holds one feature: `index.js` (Shell adapter, the class the registry
>    starts), `model.js` (pure logic) where there is logic, `prefs.js` (its preference groups),
>    `style.css` (its Shell CSS). Features never import each other.
> 5. `stylesheet.css` is generated (`make css`) from `styles/base.css` and every
>    `features/*/style.css`, and committed. The preferences are `prefs.js` + `prefs/`.
>
> How to write a feature: `docs/architecture/conventions.md`. Plan: `overhaul-plan.md`.

Target: GNOME Shell 50 (Fedora 44, Wayland). 48/49/51 differences live only in `lib/compat.js`.

## 1. Tree

```
extension.js          composition root (enable/disable)
features.js           the feature list (start order; conflicts and needs)
metadata.json  schemas/  po/  icons/
stylesheet.css        GENERATED by tools/build-css.sh, committed
styles/base.css       Shell CSS of lib/ services (glass fills, modal frames)
core/                 shared services: pure models + Shell adapters
lib/                  infrastructure without feature knowledge
lib/cleanup/          the v3 one-shot cleanup of 2.x user files
features/<name>/      one folder per feature
prefs.js  prefs/      the preferences window (sidebar shell, widgets, pages)
tests/                gjs -m unit tests (tests/run.sh)
tools/                build-css.sh, check-pack.sh, smoke/
docs/                 architecture, feature specs, research
```

Packed into the zip (`Makefile` EXTRA and `.github/workflows/pack-release.yml`): `icons lib core
features prefs features.js`, plus what `gnome-extensions pack` takes by default (`extension.js
prefs.js metadata.json stylesheet.css schemas/ po/`). `make pack-check` verifies it.

## 2. Startup and the ctx

`extension.js enable()`:
1. `Glass.configure(settings)`; `runAllMigrations(settings)` (`lib/migrations.js`).
2. `restoreLegacyButtonLayout()` (2.x `saved-button-layout`) and `restoreStale()` (every value
   left in `saved-originals`).
3. Core services: `EventHub`, `DesktopService`, `LayoutService`, `Motion` (started).
4. `FeatureRegistry.start(ctx)`; a settings `changed` handler refreshes it (except the keys
   Kiwi writes at run time: `clipboard-recording`, `migrations-done`, `saved-originals`).
5. `runCleanup()` in the background.

`disable()` mirrors it: registry stop (reverse order), services stopped, hub cleared.

`ctx` (the same object for every feature):

| Field | What |
|---|---|
| `extension`, `settings`, `gettext` | the Extension, Kiwi's `Gio.Settings`, its gettext |
| `features.instance(id)` | the running instance of another feature, or null (look up at use time) |
| `events` | `core/events.js` EventHub |
| `desktop` | `core/desktop.js` DesktopService (`acquire(cleanup)` starts tracking) |
| `layout` | `core/layout.js` LayoutService (`acquire(cleanup)`, `claim()`, `workArea()`) |
| `motion` | `core/motion.js` Motion (`ease`, `spring`, `env`) |
| `appMenus` | `core/appMenus/service.js` AppMenuService (menus of the focused app) |
| `originals` | `core/originals.js` OriginalsStore (give it to a `SettingOwner`) |

## 3. core/

| File | Role | Main API |
|---|---|---|
| `events.js` | typed signal hub; events declared once in `EVENTS` | `on(name, fn, owner?)`, `once`, `emit(name, payload)`, `listenerCount`, `clear` |
| `desktopModel.js` | pure desktop picture | `upsertWindow(id, fields)`, `removeWindow`, `window(id)`, `windows(filter)`, `apps(filter)`, `setFocus`, `focusedWindow`, `focusedApp`, `setWorkspaces`, `setMonitors`; `isHelperWindowInfo`, `isUserFacing`, `appIdCandidates` (web-app ids for window-backed apps) |
| `desktop.js` | feeds the model from Mutter; one tracker, ref-counted | `acquire(owner)`, `model`, `metaWindow(id)`, `tracking`, `stop()` |
| `layoutModel.js` | edge claims -> rects and work area | `claim(spec)`, `update(id, fields)`, `release(id)`, `compute(index, monitorRect, {base, primary, strutsApplied})` |
| `layout.js` | claims the menu bar itself; Mutter's work area as the base; an `actor` claim is chrome (hidden over full screen), with struts while its reserve is `strut` (`update({reserve})` switches live) | `acquire(owner)`, `claim(owner, spec)` -> `{rect, update, release}`, `rect(id, monitor)`, `workArea(monitor)` |
| `motionModel.js` | durations, curves, springs; animations-off and reduced-motion rules | `DURATIONS`, `CURVES`, `SPRINGS`, `resolve(request, env)`, `splitProps`, `springAt`, `springDuration`, `springKeyframes` |
| `motion.js` | applies them to actors; cancellable | `start/stop`, `env`, `duration(req)`, `ease(actor, props, req, owner)`, `spring(actor, prop, to, req, owner)` |
| `originals.js` | the user's value of GNOME keys Kiwi owns (pure; the Shell side is a Gio.Settings) | `OriginalsStore`, `SettingOwner(store, settings, key, {type, transform/value, onOriginalChanged})` with `sync/reapply/release/original`, `restoreStale(store, openSettings)`; `ListMembersOwner(store, settings, key, members)` takes only some members out of a string list (Dash to Dock from `enabled-extensions`) and adds back just those |
| `tileActions.js` | tiling vocabulary: zones, arrangements, `parseAction` (payload of `window-tile-requested`) | `ZONES`, `ARRANGEMENTS`, `parseAction` |
| `panelLayout.js` (+`Model`) | who sits where in the top bar; hides stock items | `PanelLayout.claim(cleanup, {id, actor, box, anchor})`, `PanelLayout.hide(cleanup, role)` |
| `windowState.js` | why a window is not in its normal place (`staged`, ...) | `WindowState.set/has/list/watch`, `interceptMinimize`, `setStageActive` |
| `notificationRouter.js` | banners to the notch or stock, shared `{count, dnd}` | `setBannerSink`, `pinBanners`, `connect`, `state`, `setDnd` |
| `mprisWatcher.js` | one MPRIS source for the extension | `MprisWatcher.acquire(cleanup, gettext)` |
| `appMenus/` | the focused app's menus (ctx.appMenus): pure `model.js` (generic menus, well-known GTK actions, Help search, ⌘ shortcut labels), `gtkActions.js` (org.gtk.Actions provider), `commands.js` (generic commands), `service.js` (providers, cache, activation) | `acquire(owner)`, `targetFor(win)`, `peek/results(target)`, `build(target, results, opts)`, `activate(target, command)`, `registerProvider(owner, provider)` |

Events (`EVENTS` in `core/events.js`): `window-added`, `window-changed`, `window-removed`,
`window-focused`, `app-focused`, `workspaces-changed`, `monitors-changed`, `work-area-changed`,
`motion-changed`, `feature-changed`, `minimize-requested`, `notification-center-requested`
(the clock), `app-hide-requested` and `window-tile-requested` (app-menu commands for the
window manager; the menu bar runs a fallback when nobody listens).

## 4. lib/

| File | Role |
|---|---|
| `featureRegistry.js` | the engine of `features.js` (edge-triggered, lazy `load()`, `needs`/`conflictsWith`, failure isolation, `onChange`) |
| `disposables.js` | `CleanupRegistry`: signals, timeouts, idles, injections, actors, files; `dispose()` undoes all, newest first |
| `settings.js` | `KiwiSettings` (typed access, per-key watchers), `runMigrations` |
| `migrations.js` | every key migration, and the only module (with `lib/cleanup/`) that reads deprecated keys |
| `compat.js` (+`compatModel.js`, `gioCompat.js`) | everything that differs between Shell 48-51; the reduced-motion source; shader effects; `isMaximized`, `maximizeWindow` |
| `glass.js` (+`glassParams.js`) | faux Liquid Glass service: classes and a fill fragment on every Kiwi surface, shadow hosts, Clear↔Tinted, Reduce Transparency, Increase Contrast, Show Borders (CSS in `styles/base.css`); `attach`, `attachMenu`, `watch` |
| `wallpaperTint.js` (+`wallpaperModel.js`) | the wallpaper's average colour for the glass tint (async 32×32 decode, cached per URI) |
| `modalSurface.js` (+`modalLook.js`, `modalModel.js`) | one Kiwi modal at a time (Spotlight, Quick Paste, clipboard popover) |
| `keybindings.js` (+`Model`) | registers Kiwi shortcuts, conflict list |
| `mpris.js` (+`Model`) | MPRIS players |
| `quickSettings.js` | `readyQuickSettings()`, `whenQuickSettingsReady(cleanup, fn, name)` (bounded wait) |
| `keepHidden.js` | keep a Shell actor hidden while a feature runs, give back its wanted visibility |
| `jobQueue.js` | promise queue (`createJobQueue`) |
| `cleanup/` | v3 one-shot cleanup: `index.js` (`runCleanup`, steps, `CLEANUP_ID`), `mozilla.js` (+`mozillaModel.js`), `cleanupModel.js` (gtk.css, environment.d, dock colours), `fileOps.js` (async Gio helpers, `enqueueUserFileJob`) |

Shared-resource rules (defined once in `features.js`): `window-controls`/`app-buttons` are
mirrors over `button-layout`; `control-center` beats `dnd-button`; `stage-manager` beats
`move-window-to-new-workspace`; the notch forces the calendar to the right.

## 6. Preferences

`prefs.js` builds the window from `prefs/pages/index.js` `SECTIONS`; `prefs/window.js` is the
sidebar (sections, search across every row, narrow-window collapse); `prefs/widgets.js` the
shared rows; each page module composes `features/<name>/prefs.js` `buildPrefs()` groups.
Order: General | Menu Bar, Dock, Windows, Stage Manager | Notch, Spotlight, Control Center,
Clipboard | Appearance | About.

## 7. Settings

`schemas/org.gnome.shell.extensions.kiwi.gschema.xml` groups keys by feature. Keys of dropped
features stay one release as "(Deprecated, unused)", then go; `tests/architecture.test.js`
fails if any code but `lib/migrations.js` and `lib/cleanup/` reads one. Internal keys:
`migrations-done`, `saved-originals`, `clipboard-recording`.

## 8. Tests and checks

`make check` = eslint (pure modules may not import `gi://`/`resource://`; prefs may not import
Shell modules; Shell code may not import GTK) + strict schema compile + `make css-check` +
`tests/run.sh` (every `tests/*.test.js` under `gjs -m`). `make pack-check` packs and checks the
zip. Real Shell: `KIWI_SRC=$PWD /tmp/x2/run-f44.sh 20` (see `.swarm/shared/ux-round.md`).
