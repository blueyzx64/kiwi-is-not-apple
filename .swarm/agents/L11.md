## Findings for orchestrator
- **Widget slot API for L10 (Notification Center) and L9 (notch Widgets tab)** — one model in `core/widgets/`:
  - `import { Widgets } from '../../core/widgets/index.js'; const host = Widgets.acquire(cleanup, ctx.gettext);`
  - `host.registry.kinds()` / `.find({query, category, translate})` / `.categories()` / `.sizesFor(kind, 'center'|'notch'|'desktop')` (no extra-large outside the desktop).
  - `const view = host.createView(kind, {size, config, scale}, cleanup)`: `view.actor` is a fixed-size faux-glass card (small 160x160, medium 336x160, large 336x336 at scale 1; `pixelSize()` in core/widgets/view.js). Add it to your column; call `view.setActive(true)` while your surface is open and `false` when it closes (providers stop when no active view needs them). `view.activate()` = click (opens the app); `view.menuItems()` = kind options.
  - Persist your own list with `parseLayout/serializeLayout/addItem/removeItem/resizeItem` from core/widgets/model.js (use a fixed `monitor` key such as 'center'), in your own settings key.
  - "Edit Widgets…" from the Notification Center: `ctx.features.instance('desktop-widgets')?.editWidgets()` (null while the feature is off).
  - Card CSS (`.kiwi-widget*`) lives in features/widgets/style.css but is global, so it works while desktop-widgets is off.
- extension.js: `widgets-layout` added to KEYS_THAT_NEVER_AFFECT_FEATURES (one-word hunk).
- Clicking empty wallpaper does not unset focus in GNOME, so "Automatic" goes full colour only on Show Desktop / Stage Manager desktop / nothing focused. A click-wallpaper feature (P3) that unsets focus would complete the macOS behaviour.
