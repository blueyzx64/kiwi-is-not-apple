## Findings for orchestrator
- The harness copies only KIWI_PRE and KIWI_EXTRA into the chroot (/opt). `/home/user` is not visible there, so a script cannot `source` lib.sh by path. Bundle it first.
- P returns JSON.stringify(result) inside a gdbus tuple: `true` prints as `('true',)`.
- Clutter has no keysym_from_name in GI. Keys are `Clutter['KEY_'+name]` (verified in the f44 Clutter-18.typelib).
- t-cc/pre.sh and t-notch/pre.sh run session-bus mocks (gsd_rfkill, SettingsDaemon.Power) before dbus-run-session starts. Those calls cannot work pre-Shell, so the library leaves them out.
